# Romantic Invitation

Open `index.html` in any modern browser. This is a single-page, mobile-first invitation: its screens fade in place instead of reloading, so the supplied `background-music.mp3` continues playing after the envelope is opened. A live countdown targets the next September 22 at 12:00 AM (Philippine time). It also uses a softly faded Makati City photograph from Unsplash as the backdrop, so an internet connection is needed for that image.
